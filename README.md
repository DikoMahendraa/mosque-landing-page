## 🌟 Features

### 📱 Digital Facilities (Fasilitas)
- **Prayer Times** - Real-time countdown and daily prayer schedule powered by Aladhan API
- **Qibla Direction** - Interactive compass using device orientation sensors
- **Nearby Mosques** - Find mosques within 5km using OpenStreetMap

### 📅 Community Features
- **Events Management** - Browse and register for mosque events
- **Kajian (Islamic Studies)** - Schedule and content for Islamic learning sessions
- **News & Announcements** - Latest updates from the mosque
- **Financial Transparency** - Public financial reports and donation tracking

### 💻 Technical Features
- **Responsive Design** - Optimized for mobile, tablet, and desktop
- **Dark Mode Support** - Eye-friendly theme switching
- **SEO Optimized** - Enhanced search engine visibility
- **WhatsApp Integration** - Quick contact and registration
- **Floating Prayer Widget** - Always-visible prayer time countdown

## 🚀 Overview

A comprehensive digital platform built with Next.js and modern web technologies to serve the mosque community. This platform provides essential worship tools, event management, and transparent communication channels.

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (React 19)
- **Styling:** Tailwind CSS 4.1 + shadcn/ui
- **Animations:** Framer Motion
- **Database:** Supabase
- **APIs:** Aladhan (Prayer Times), OpenStreetMap (Nearby Mosques)
- **Deployment:** Vercel
